About this piece

The perfect gift for the avid reader in your life! Our "Books Read this year" hanging sign is a fun, interactive and stylish way to keep track of your reading progress all year long! This item is an Original Side Quest Co. design! Designed to be hung using XL velcro command strips that hide seamlessly inside a hollow rectangular mounting base.

The set includes 29 number tags along with a small container to help keep them all in one spot, allowing you to count from 0 all the way up to 999 books read!
